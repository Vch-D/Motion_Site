# Проверки менеджера (Reviews)

Запускают отдельный «безголовый» Chrome со своим временным профилем, ничего не отправляют наружу.
Нужен локальный сервер сайта: `python3 -m http.server 5173 --bind 127.0.0.1` из папки сайта.

- `rvtest.py` — весь сценарий в демо-режиме менеджера: исполнитель отправляет видео, заметки на кадрах,
  владелец просит правки, v2, финал ссылкой, одобрение финала, удаление версии, вид на телефоне.
- `remotetest.py` — режим Supabase против поддельного supabase-js (`fake-supabase.js`): какие именно записи
  уходят в базу и хранилище, в базе с `reviews.sql` и без неё, лимит 50 МБ, одновременные версии.

Видео для теста: `TEST_VIDEO=/путь/к/короткому.mp4 python3 rvtest.py`. В конце печатается `RESULT: ALL PASSED`.
