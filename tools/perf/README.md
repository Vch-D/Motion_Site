# Замеры производительности сайта

Скрипты запускают отдельный «безголовый» Chrome (свой временный профиль, окно не открывается,
обычный браузер не трогают) и гоняют сайт по сценариям: смена слов, меню, WORKS, CLIENTS, CONTACT.
Нужны только `python3` и Google Chrome. Сайт должен быть открыт локально:

```bash
cd "/Users/mp/Desktop/Motion Site" && python3 -m http.server 5173 --bind 127.0.0.1
```

| Скрипт | Что делает |
| --- | --- |
| `thru.py <url> <метка>` | Скорость кадров без ограничения частоты: медиана и p95 времени кадра по сценариям. Главная цифра «стало быстрее / медленнее». |
| `bench.py <url> <метка> [сценарии]` | То же на обычных 60 Гц с трассировкой Chrome: стили, вёрстка, отрисовка, растеризация, загрузка GPU-процесса, пропущенные кадры. `BENCH_CSS="..."` подмешивает CSS (удобно отключать эффекты по одному). |
| `shots.py <url> <метка>` | Детерминированные скриншоты 12 состояний (часы и случайные числа заморожены). |
| `diff.py <меткаА> <меткаБ>` | Попиксельное сравнение двух наборов скриншотов (нужен `python3 -m http.server 5176` в этой папке). `fmt.py` делает вывод читаемым. |

Типичная проверка перед выкладкой правок в анимации:

```bash
python3 thru.py http://127.0.0.1:5173/ after
```

Сравнить с прошлым запуском (`thru-*.json`). Экраны в покое должны показывать `idle 100%`:
это значит, что браузер вообще ничего не перерисовывает.
